02 / THE QUICK REFERENCE

Find the command you need

Grouped by task, so you can scan first and remember faster.

01

Get started

Set up a repository and check its current state.

03 COMMANDS
  • CREATE01
    git init

    Start a new Git repository in the current folder.

  • COPY02
    git clone <url>

    Copy an existing repository to your computer.

  • INSPECT03
    git status

    See which files changed and which changes are staged.

02

Save your work

Choose changes, create snapshots, and review history.

03 COMMANDS
  • STAGE04
    git add .

    Stage all changes in the current folder for the next commit.

  • SNAPSHOT05
    git commit -m "message"

    Save staged changes with a short, meaningful message.

  • HISTORY06
    git log --oneline

    Review recent commits in a compact list.

03

Branch and merge

Work on features separately, then combine changes.

03 COMMANDS
  • CREATE BRANCH07
    git branch <name>

    Create a branch for a feature or experiment.

  • SWITCH08
    git switch <name>

    Move to an existing branch.

  • COMBINE09
    git merge <name>

    Merge another branch into your current branch.

04

Share and undo

Sync with a remote repository and safely undo a change.

03 COMMANDS
  • UPLOAD10
    git push

    Send your local commits to the remote repository.

  • UPDATE11
    git pull

    Fetch remote changes and integrate them into your current branch.

  • UNDO SAFELY12
    git revert <commit>

    Create a new commit that reverses the effects of an earlier commit.
