Commands

The everyday git commands, at a glance.

Get started

  • git init

    Start a new repository in the current folder.

  • git clone <url>

    Copy an existing repository to your machine.

  • git status

    See which files changed and what is staged.

Save your work

  • git add .

    Stage all changes for the next commit.

  • git commit -m "message"

    Save a snapshot of the staged changes.

  • git log --oneline

    Browse the commit history in a compact list.

Branch and merge

  • git branch <name>

    Create a new branch.

  • git switch <name>

    Move to another branch.

  • git merge <name>

    Combine another branch into the current one.

Share and undo

  • git push

    Upload your commits to the remote repository.

  • git pull

    Download and merge the latest remote changes.

  • git revert <commit>

    Undo a commit by adding a new one.
